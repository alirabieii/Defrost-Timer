# ❄️ Refrigerator Defrost Timer

![Platform](https://img.shields.io/badge/MCU-ATmega8A-blue)
![Compiler](https://img.shields.io/badge/BASCOM-AVR-green)
![Display](https://img.shields.io/badge/Display-TM1637-orange)
![License](https://img.shields.io/badge/Status-Open--Source-lightgrey)

A refrigerator **Defrost Timer** project developed using **BASCOM-AVR** and based on the **ATmega8A/L** microcontroller.

The system is designed to manage refrigeration and defrost cycles and supports connection to an **external display and control keypad**.

---

## ✨ Features

- BASCOM-AVR firmware
- ATmega8A/L microcontroller
- TM1637 4-digit display support
- External display and keypad interface
- 3 relay outputs
- 2× NTC 10K sensor inputs
- Lightweight multitasking / RTOS structure
- Interrupt-based timers
- Suitable for refrigeration and defrost control

---

## 🛠 Hardware

| Component | Description |
|---|---|
| MCU | ATmega8A/L |
| Display | TM1637 4-Digit 7-Segment |
| Sensors | 2× NTC 10K |
| Outputs | 3 Relay Outputs |
